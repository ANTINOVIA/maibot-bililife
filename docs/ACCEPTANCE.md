## 自动化验证范围

本地 Python 3.12，pytest 覆盖：计划唯一性/修订、并发额度事务、锁与恢复、取消、
超时及错误状态、draft_only 禁止自动发布、自动模式额度冷却近似重复、未知发布不重试、
发布前取消、真实库回复参数签名、通知线程映射、待处理回复恢复、记忆检索/遗忘/注入状态、
兴趣冻结回滚、恶意外部指令不能改权限、证据不足拒绝发布、无字幕降级、
提供商凭据不回显/地址绑定/能力验证、协议构造、媒体重试不重复输入、跨日复盘及摘要修订。
媒体和发布策略中的替身测试不代表对应远端模型或真实回复已经成功。
最终全套结果：**36 passed in 58.67s**。WebUI 构建和 Node 语法检查通过，
九页声明通过本机保存的服务器真实 schema 校验。

真实复盘曾出现“字幕错误”的无音频依据断言，复查任务如实进入 failed，而非保存为新事实。
新增有限修复后的保守路径：反复不合格时只从实际执行记录汇总数量、范围及来源，
明确显示 `degraded` 和证据校验错误，不虚构知识、听感或兴趣变化。旧摘要版本保留审计。
