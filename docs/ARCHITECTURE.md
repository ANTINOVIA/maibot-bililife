# 架构与信任边界

`plugin.py` 仅实现已核实 SDK 的生命周期、静态 API 和只读记忆工具。
`MaiBotAdapter` 从 `config.get("personality")` 读取人格，经 `llm.generate` 使用宿主模型角色。
角色调用保留提示词版本、真实返回模型名、供应商 usage 和错误状态。

`BilibiliAdapter` 复用固定版本 17.4.2 的平台库读取能力。写请求复用上游经审查的签名准备，
通过无重试 HTTPX 单次提交；签名库内部接口与该固定版本绑定，不应盲目升级。
搜索、指定 UP 主、推荐读取均访问真实接口，不向界面填充静态数据。
推荐和回复通知依赖账号/平台条件；失败显示真实错误，不实现验证码绕过或账号轮换。

`DailyPlanner` 让模型提出结构化任务，再由程序核验日期、时段、主题、数量、时长和依赖 DAG。
模型不能指定 Shell、方法名或任意 HTTP 请求。非法结构只修复一次，仍失败则降级为休息并
记录计划错误。`TaskExecutor` 管理任务状态、资源、取消、期限和恢复；不跨进程共享内存队列。

`VideoUnderstanding` 按字幕、有限音频和关键帧取得证据。理解细节引用必须在资料文本或帧标签
中存在，语义引用不合法时只额外修复一次；证据和推断有单独字段。
`InteractionService` 负责草稿、outbox、线程校验及统一发布策略。
`MemoryBridge` 存储插件记忆并注册到宿主可调用工具；没有声称 SQLite 写入等于宿主长期写入。
`PersonaEvolution` 只修改有限兴趣维度。`WebUIService` 提供短查询和持久化操作。
复盘逐条检查感官证据，有限修复仍不通过时只生成执行记录汇总，保留降级标记与原因；
模型不可用或预算不足仍显示真实任务错误。提前手动复盘不会阻止配置时间的正式复盘。

SQLite 同步操作、文件 I/O 和 CPU 工作经 `asyncio.to_thread`；下载与外部程序使用异步接口。
文件锁约束同一台机器上的同一数据目录，不支持多台服务器共享 SQLite 或 NFS 分布式部署。
任务 lease 和 owner 记录用于审计和恢复；排他文件锁与有界任务时限是此单机实现的主互斥机制。

资源预扣是保守控制：模型按输入字符、图像余量和输出上限预留，响应 usage 可用时结算。
供应商 usage 缺失/请求超时时保留预扣；供应商意外超报也如实入账并阻止后续消耗。
这不能严格限制远端模型在超时后继续运行产生的供应商账单。媒体按实际收到的字节计量；
平台小型 JSON 请求不等同于网络链路总流量，TLS/协议开销不计入媒体下载额度。
数据库达到容量上限会停止新增消耗；历史发布 outbox 不会因保留策略清除，防止失去去重依据。

字幕、评论和页面文本均放在明确的外部资料字段，提示词不授予它们权限；真正权限由后端程序
校验。恶意文本不能获得发布工具、文件路径或 Shell 执行能力。提示词防注入不是完整信息流证明；
不将真实账号凭据或私人聊天传给视频分析模型是重要的隔离措施。

运行时提示词保存在 `prompts/runtime.json`，统一版本及九个阶段可分别维护；管理员只能追加有限
文字说明，不能改变后端权限、预算或 Schema。模型非法结构、缺少正文或服务异常都进入真实状态。
