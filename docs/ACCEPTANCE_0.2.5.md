# 0.2.5 交付与验收

版本日期：2026-10-23，业务时区 Asia/Shanghai。安装目标保持 MaiBot 1.3.14 /
SDK 2.16.0 / dashboard 1.9.8，不升级宿主。

## 已实现

| 需求 | 实现位置及行为 |
| --- | --- |
| 直接选择 MaiBot 模型 | 每个用途下拉框直接列出宿主模型；保存 `host:模型名`，不要求创建继承条目，没有“沿用”选项 |
| 独立提供商可配置 | 单独新增表单/TOML、后端校验、地址与密钥绑定；不能把能力声明当作可用性证明 |
| 兴趣与人格干预 | 人工设置兴趣权重/冻结/原因；人格偏好和表达说明版本化、可回滚；不改宿主核心身份或权限 |
| 日程直观展示 | 24小时钟面与彩色时段环、任务列表、日期切换；重叠分层，实际状态单独展示 |
| 重新生成、插入、删除 | 新计划版本、指定日期/时段插入、删除即取消并隐藏；保留审计，恢复显示不重新执行 |
| 去除运行模式 | 删除业务Schema中的mode；浏览、评论、回复、记忆、兴趣、复盘分别配置，旧权限保守迁移 |
| 自定义每日量 | 浏览页设置浏览数/时长；评论与回复分别设置每日额度、冷却和检查频率；其他模块亦有对应表单 |
| 设置是模块总览 | 账号与模块卡片概况，可直接跳转；测试结果留在相应模型用途下，不集中在测试中心 |
| 融合 MaiBot | 采用已安装 dashboard 的 `--maibot-*` 变量、`.maibot-page/.maibot-card/.maibot-button` 与真实主题桥接 |
| TOML 输入 | 模块与全量业务配置、模型路由、独立提供商均有TOML入口和示例；密钥不进入普通配置导出 |

## 仍有边界

- 用户已经同意浏览器检查，但应用保存策略仍拒绝本地来源网络访问。没有改用其他浏览器或原始协议绕过，因此视觉/手机人工验收尚未完成。
- 音频/视频模型需要用户配置可用服务才能做真实推理验收；选择某个宿主模型不会自动赋予其音视频能力。
- 视频理解仍使用有界片段，不能称为实时无限视频流或完整观看。
- 当前宿主长期记忆写入接口仍不支持；已验证的真实独立对话召回与上下文追加见0.2.0历史验收。
